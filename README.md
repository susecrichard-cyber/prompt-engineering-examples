# Prompt Engineering Examples

Prompt engineering examples and patterns for working with large language models.

Built by Richard Frimpong.

## What is in here

- `prompts.md` — example prompts for ask, explain, brainstorm, draft, plan, and summarize, with notes on what makes each one work.
- `prompt_example.py` — a small script that builds a prompt from a template, so the same pattern can be reused with different inputs.

These are example prompts and patterns, not production prompts for a specific client.

## How to use them

Pick a pattern from `prompts.md`, replace the bracketed parts like `[topic]` with your own topic, and try it with the model you are using.
